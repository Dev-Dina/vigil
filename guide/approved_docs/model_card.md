# Vigil — Model Card (public summary)

This is a public, honest summary of Vigil's Phase-3 modelling. Every number here matches the
project's internal model cards (`data/models/**`, `PHASE3_CARD.md`); nothing is rounded up or
overstated. Where a result is negative or limited, it is stated plainly.

## Two layers of evidence

### 1. Registry-scale structural baseline — REAL public data
- **Source:** real, public ClinicalTrials.gov / AACT trial-level data (a modelling cohort of
  ~37,000 trials / ~97,000 arms), split by time so the test window is the most recent period.
  Aggregate per-arm data only — **no patient-level data, no PHI**.
- **Headline:** pan-indication test PR-AUC = **0.697** for predicting high-dropout arms.
- **The honest caveat:** that 0.697 is **substantially inflated by base-rate differences between
  indications** — the model largely learns *which disease area* has higher baseline dropout, not
  within-trial participant risk. Read against each indication on its own test fold the picture is
  weaker and varies widely:

  | Indication | test arms | within-indication PR-AUC |
  |---|---|---|
  | T2D (type-2 diabetes) | 516 | 0.38 |
  | Psoriasis | 240 | 0.65 |
  | IBD | 229 | 0.50 |
  | Alzheimer's | 172 | 0.77 (directional only — small n, no CI) |
  | Depression (MDD) | 152 | 0.32 |
  | Multiple sclerosis | 142 | 0.62 |
  | Heart failure | 107 | 0.58 |

  These are single-split point estimates with **no confidence intervals** (a deferred hardening
  item). The Alzheimer's 0.77 in particular rests on only 172 test arms and must be read as
  directional, not as an established "strong-signal" ranking.

### 2. Visit-trajectory modelling — SYNTHETIC cohort (clearly labelled)
To test whether *visit-attendance patterns* add predictive signal beyond static covariates, the
project used a **fully synthetic** type-2-diabetes cohort whose trajectories were generated by a
planted disengagement rule, calibrated to real published trial statistics. This proves the
**method and architecture**, not clinical validity.

- A sequence model over covariates + visit trajectory reached test PR-AUC **0.339**, versus a
  covariates-only structural baseline of **0.251** — a **+0.088** lift, the one real
  discriminative gain in this phase. The bar (≥ 0.3006) was **pre-registered before the fit** and
  met.
- A time-to-event (survival) model was a **negative result**: C-index ≈ **0.40** (about chance /
  slightly anti-concordant). It is reported honestly as a negative, not dressed up.
- The synthetic cohort passed its calibration checks, and the latent generator variable was never
  used as a model feature (which would have trivially recovered the planted rule).

## What this does NOT prove (read this)
- The 0.697 figure is **not** a clinical prediction accuracy; it largely reflects learned
  per-indication base rates.
- The +0.088 trajectory lift is **not** validated on real individual-participant data — the
  trajectories are synthetic.
- The 0.40 survival C-index is a **negative** result on a synthetic cohort, not a working
  survival model.
- Some covariate values in the synthetic cohort (e.g. BMI, HbA1c) are **literature-prior
  imputations** calibrated to published population statistics — they are labelled as such and are
  **not** real patient measurements.
- **No PHI was used at any stage.**

## Honest bottom line
Static registry features predict *between-indication* dropout variation but capture mostly base
rates, not within-trial participant risk. Visit-trajectory features add a real, modest lift on a
synthetic cohort — enough to demonstrate the architecture and the evaluation discipline.
Clinically validating the trajectory hypothesis would require real longitudinal data that this
portfolio does not use.
